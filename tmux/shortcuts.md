# Ghostty + tmux 快捷键

Ghostty 负责一个终端窗口，tmux 管理内部的 tabs 和面板。
下文的 tab 对应 tmux window，面板对应 tmux pane。
字母键沿用 Ghostty 当前键盘布局的识别方式。

## 面板

| 快捷键 | 操作 |
| --- | --- |
| ⌘D | 左右分屏，新面板在右侧 |
| ⌘⇧D | 上下分屏，新面板在下方 |
| ⌘W | 关闭当前面板，先确认 |
| ⌘[ / ⌘] | 上一个 / 下一个面板 |
| ⌘⌥↑↓←→ | 按方向切换面板 |
| ⌘⌃↑↓←→ | 按方向调整面板大小，每次 10 个字符单元 |
| ⌘⌃= | 均分当前面板及其相邻面板 |
| ⌘⇧Enter | 当前面板放大 / 恢复 |
| 鼠标悬停 | 激活对应面板 |

新面板继承当前面板的工作目录。

## Tabs

| 快捷键 | 操作 |
| --- | --- |
| ⌘T | 创建 tmux tab，继承当前工作目录 |
| ⌘⇧[ / ⌘⇧] | 上一个 / 下一个 tab |
| ⌃⇧Tab / ⌃Tab | 上一个 / 下一个 tab |
| ⌘1–8 | 切换到从左到右第 1–8 个 tab |
| ⌘9 | 切换到最后一个 tab |
| ⌘⌥W | 关闭当前 tab 及全部面板，先确认 |
| 点击顶部 `[编号:名称]` | 切换 tab |

## 仍由 Ghostty 或前台程序处理

| 快捷键 | 操作 |
| --- | --- |
| ⌘C / ⌘V | Ghostty 复制 / 粘贴 |
| ⌘+ / ⌘− / ⌘0 | 调整 / 恢复终端字号 |
| ⌘Enter 或 ⌘⌃F | 切换 Ghostty 全屏 |
| ⌘⇧, | 重载 Ghostty 配置 |
| F13 | 全局显示 / 隐藏 Ghostty |
| ⌘Q | 退出 Ghostty；tmux 会话中的程序继续运行 |
| Shift+Enter | 发送给前台程序，支持时用于换行 |
| Ctrl+C / Ctrl+D / Ctrl+W | 发送给前台程序 |
| ⌘N、⌘⇧W、⌘⌥⇧W | 已禁用 |

关闭面板会结束其中的 shell、Codex 或 Claude。确认提示中按 `y` 关闭，
按 `n` 或 Escape 取消。只想隐藏界面时用 F13。

关闭一个 tab 的最后面板会关闭该 tab；关闭会话的最后 tab 会结束 tmux
会话，Ghostty 终端也可能随之关闭。Ctrl+D 的含义取决于前台程序，不能代替关闭面板。

## tmux 默认快捷键仍可用

先按 Ctrl+B，松开后再按下表中的键。

| 后续按键 | 操作 |
| --- | --- |
| `%` / `"` | 左右 / 上下分屏 |
| `o` / 方向键 | 下一个面板 / 按方向切换 |
| Ctrl+方向键 / Alt+方向键 | 按方向调整 1 / 5 个字符单元 |
| `E` | 均分当前面板及相邻面板 |
| `z` | 当前面板放大 / 恢复 |
| `x` | 关闭面板，先确认 |
| `c` | 创建 tab |
| `n` / `p` | 下一个 / 上一个 tab |
| `1–9` | 切换到对应编号的 tab |
| `&` | 关闭 tab 及全部面板，先确认 |
| `,` | 重命名 tab |
| `[` | 进入 tmux 历史滚动 / 复制模式；按 `q` 退出 |
| `d` | 分离客户端，保留会话和运行中的程序 |
| `:` | 打开 tmux 命令提示符 |
| `Ctrl+R` | 同时刷新 Codex 和 Claude 的 usage |

Usage 手动刷新会绕过 Codex 的 3 分钟间隔；Claude 只在手动刷新时独立查询，用于检查提前重置。
可以按住 Ctrl，依次按 B、R；查询在后台执行。单独 Ctrl+R 仍交给前台程序，
例如 shell 的历史搜索。

## 专注倒计时

状态栏最右侧自动循环：52 分钟 Focus（绿色）→ 17 分钟 Break（灰色）。
剩余时间显示在 12 格进度条内部靠左，每秒刷新；色块表示剩余时间。
数字在绿色或浅灰色填充上用深色，在深色底轨上用白色。
Focus 最后 60 秒的标签和剩余时间变黄，并在屏幕中央显示一次 macOS 原生浮层：
**1 minute remaining**。5 秒后自动消失，无按钮、无需确认，点击穿透且不抢键盘焦点。
Break 保持灰色，不提醒。
多个客户端共享提醒记录，重载不会重复提醒；重置计时会开始新一轮。
提醒只在剩余 55–60 秒的状态栏刷新时出现，需要仍有客户端连接；重连或唤醒时
已经错过这个窗口就不补发。浮层显示前会再次检查截止时间。
提醒失败会短暂显示状态消息，不进入 view-mode；完整原因保存在
`~/.cache/tmux-focus/reminder-error.log`（遵循 `$XDG_CACHE_HOME`），只保留最近一次、
最多 4 KiB。本轮不会反复重试。

唯一命令是 `tmux focus-restart`，立即重新开始 52 分钟 Focus。
也可以按 Ctrl+B → `:`，输入 `focus-restart`。
单击倒计时的标签或进度条同样会重新开始。
重载配置、分离或重新连接不会重置进度；休眠期间仍按实际经过时间计算。

## 状态栏鼠标操作

| 区块 | 操作 |
| --- | --- |
| Codex 标签、进度条或余额 | 单击打开 ChatGPT usage 页面 |
| Claude 标签或任一进度条 | 单击打开 Claude usage 页面 |
| Focus / Break 标签或进度条 | 单击重新开始 52 分钟 Focus |

页面使用系统默认浏览器打开；竖线分隔符没有点击动作。

## 使用边界

- 这是单 Ghostty 窗口的操作方案，并非强制窗口数量限制。应用菜单和 Dock
  拖入文件仍能创建原生窗口；⌘N 已禁用，日常新增工作区使用 ⌘T。
- 在 SSH 或嵌套 tmux 中，Command 快捷键仍控制最外层 tmux 的面板和 tabs。
- ⌘9 沿用 Ghostty 的“最后一个 tab”语义，Ctrl+B → `9` 则选择编号 9。
- 关闭 tab 后编号自动从 1 连续排列，⌘1–8 与从左到右的位置一致。
- 重载后先按 ⌘⇧, 让 Ghostty 使用新映射；tmux 使用
  `tmux source-file ~/.tmux.conf` 重载。
