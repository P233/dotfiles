# Ghostty + tmux 快捷键

Ghostty 负责一个终端窗口，tmux 管理内部的 tabs 和面板。
下文的 tab 对应 tmux window，面板对应 tmux pane。
字母键沿用 Ghostty 当前键盘布局的识别方式。

## 面板

| 快捷键 | 操作 |
| --- | --- |
| ⌘D | 左右分屏，新面板在右侧 |
| ⌘⇧D | 上下分屏，新面板在下方 |
| ⌘W | 关闭当前面板，先确认 |
| ⌘[ / ⌘] | 上一个 / 下一个面板 |
| ⌘⌥↑↓←→ | 按方向切换面板 |
| ⌘⌃↑↓←→ | 按方向调整面板大小，每次 10 个字符单元 |
| ⌘⌃= | 均分当前面板及其相邻面板 |
| ⌘⇧Enter | 当前面板放大 / 恢复 |
| 鼠标悬停 | 激活对应面板 |

新面板继承当前面板的工作目录。

## Tabs

| 快捷键 | 操作 |
| --- | --- |
| ⌘T | 创建 tmux tab，继承当前工作目录 |
| ⌘⇧[ / ⌘⇧] | 上一个 / 下一个 tab |
| ⌃⇧Tab / ⌃Tab | 上一个 / 下一个 tab |
| ⌘1–8 | 切换到对应编号的 tab |
| ⌘9 | 切换到最后一个 tab |
| ⌘⌥W | 关闭当前 tab 及全部面板，先确认 |
| 点击顶部 `[编号:名称]` | 切换 tab |

## 仍由 Ghostty 或前台程序处理

| 快捷键 | 操作 |
| --- | --- |
| ⌘C / ⌘V | Ghostty 复制 / 粘贴 |
| ⌘+ / ⌘− / ⌘0 | 调整 / 恢复终端字号 |
| ⌘Enter 或 ⌘⌃F | 切换 Ghostty 全屏 |
| ⌘⇧, | 重载 Ghostty 配置 |
| F13 | 全局显示 / 隐藏 Ghostty |
| ⌘Q | 退出 Ghostty；tmux 会话中的程序继续运行 |
| Shift+Enter | 发送给前台程序，支持时用于换行 |
| Ctrl+C / Ctrl+D / Ctrl+W | 发送给前台程序 |
| ⌘N、⌘⇧W、⌘⌥⇧W | 已禁用 |

关闭面板会结束其中的 shell、Codex 或 Claude。确认提示中按 `y` 关闭，
按 `n` 或 Escape 取消。只想隐藏界面时用 F13。

关闭一个 tab 的最后面板会关闭该 tab；关闭会话的最后 tab 会结束 tmux
会话，Ghostty 终端也可能随之关闭。Ctrl+D 的含义取决于前台程序，不能代替关闭面板。

## tmux 默认快捷键仍可用

先按 Ctrl+B，松开后再按下表中的键。

| 后续按键 | 操作 |
| --- | --- |
| `%` / `"` | 左右 / 上下分屏 |
| `o` / 方向键 | 下一个面板 / 按方向切换 |
| Ctrl+方向键 / Alt+方向键 | 按方向调整 1 / 5 个字符单元 |
| `E` | 均分当前面板及相邻面板 |
| `z` | 当前面板放大 / 恢复 |
| `x` | 关闭面板，先确认 |
| `c` | 创建 tab |
| `n` / `p` | 下一个 / 上一个 tab |
| `1–9` | 切换到对应编号的 tab |
| `&` | 关闭 tab 及全部面板，先确认 |
| `,` | 重命名 tab |
| `[` | 进入 tmux 历史滚动 / 复制模式；按 `q` 退出 |
| `d` | 分离客户端，保留会话和运行中的程序 |
| `:` | 打开 tmux 命令提示符 |
| `Ctrl+R` | 同时刷新 Codex 和 Claude 的 usage |

Usage 手动刷新会绕过 Codex 的 3 分钟间隔；Claude 只在手动刷新时独立查询，用于检查提前重置。
可以按住 Ctrl，依次按 B、R；查询在后台执行。单独 Ctrl+R 仍交给前台程序，
例如 shell 的历史搜索。

## 使用边界

- 这是单 Ghostty 窗口的操作方案，并非强制窗口数量限制。应用菜单和 Dock
  拖入文件仍能创建原生窗口；⌘N 已禁用，日常新增工作区使用 ⌘T。
- 在 SSH 或嵌套 tmux 中，Command 快捷键仍控制最外层 tmux 的面板和 tabs。
- ⌘9 沿用 Ghostty 的“最后一个 tab”语义，Ctrl+B → `9` 则选择编号 9。
- tmux tab 编号可能有空缺；数字快捷键按编号选择，不按显示位置选择。
- 重载后先按 ⌘⇧, 让 Ghostty 使用新映射；tmux 使用
  `tmux source-file ~/.tmux.conf` 重载。
